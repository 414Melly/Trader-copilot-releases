# Trader Copilot — Releases

Download the latest installer from the [Releases page](../../releases/latest).

This repository holds **only** the packaged Windows installer and the
`latest.json` manifest the app uses to update itself. The application source
code is private.

**Windows 10/11 (64-bit).** The build isn't code-signed yet, so Windows
SmartScreen will warn on first run — choose *More info → Run anyway*.
