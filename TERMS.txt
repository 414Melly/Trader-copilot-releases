3. YOUR DATA STAYS ON YOUR COMPUTER
--------------------------------------------------------------------------
Trader Copilot stores your journal, screenshots and recordings locally on your
own machine. It does not transmit them anywhere. There is no account, no login
and no server component.

The ONLY network request the application makes is an update check to GitHub,
which sends nothing about you beyond what any ordinary file download involves
(your IP address and the fact that a file was requested). You can confirm this
yourself with any network monitor.

Because everything is local, YOU are responsible for backing up your data. The
app keeps several rotating backups in its data folder (Settings → Open data
folder), but there is no cloud copy and no restore button yet. If your disk
fails, your journal is gone.

If you choose to send a bug report, only what you personally paste or attach is
shared. Nothing is collected automatically.
